# 🎯 PHASE OBJECTIVES

   * outputs generated

## CRITICAL UX FIX (MANDATORY)

### ❗ Replace horizontal scrolling workflow with DRAGGABLE CANVAS

Current problem:

* Workflow steps are laid out horizontally
* Requires scrolling
* Breaks with >2 steps
* Not usable

### REQUIRED BEHAVIOR

Implement a **true canvas system**:

#### Canvas behavior:

* Click + drag anywhere → pan canvas
* Mouse wheel / trackpad → zoom in/out
* Fit-to-view on load
* Nodes positioned freely (not locked in row)
* Nodes remain where user drags them
* No snapping entire graph on interaction

#### Node behavior:

* Each step = draggable node
* Agent(s) = node(s)
* Skills/tools optionally rendered as child or linked nodes
* Clicking a node:

  * opens Step Inspector (right panel)
  * does NOT reset graph physics

#### Layout:

* Initial auto layout (simple):

  * left-to-right or radial
* After that:

  * user-controlled positioning
