# 🧱 A. FLOW VIEW (MAJOR UPGRADE)

Replace the current vertical/static flow with a **horizontal, fluid orchestration lane**.

## Requirements

* Horizontal layout (default on desktop)
* Scrollable / pannable if needed
* Steps rendered as **cards/nodes in a sequence**
* Smooth connector lines between steps
* Responsive collapse/expand behavior

## Each step card must show:

Collapsed state:

* step number
* step name
* role badge (Primary / Specialist)
* small status indicator (idle for now)
* small "inspect" icon/button

Expanded / inspected state:

* description
* skills (chips)
* tools (chips)
* prompt (if available)
* output definition (if present)
* metadata (optional placeholder)

## Interaction

* Click step → open **Step Inspector**
* Hover → highlight + subtle animation
* Optional:

  * "focus" button centers step
  * keyboard navigation later-ready

## Step Inspector (IMPORTANT)

Implement as:

* right drawer OR floating panel (modular component)

Shows:

* full step detail
* skills/tools expanded
* prompt text
* output info
* metadata (placeholder)
* future trace/log hooks

Must be reusable for:

* Flow
* Graph
* future runtime

# 🧠 B. GRAPH VIEW (REAL IMPLEMENTATION)

Replace placeholder graph with a real interactive graph.

## Use:

* react-force-graph OR equivalent

## Graph structure

Nodes:

* agent(s)
* steps
* skills
* tools
* outputs

Edges:

* step → step (sequence)
* step → skill/tool (usage)
* step → output (result)

## Behavior

* force-directed layout (nodes drift slightly)
* nodes repel and settle
* edges animate subtly (pulse/fade)
* nodes glow lightly

## Interaction

* hover → highlight node + connected edges
* click:

  * step → open Step Inspector
  * agent → open agent detail (placeholder)
  * skill/tool → show detail (placeholder panel)

## Visual rules

* agent nodes visually distinct
* step nodes central
* skills/tools branch outward
* outputs downstream

## IMPORTANT

This graph must represent:

```text
Instance-only structure
```

NOT:

* full workspace
* all agents globally
